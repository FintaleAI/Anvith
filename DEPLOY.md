# Deployment — AnvithBizCap (Next.js 16 + Prisma/SQLite)

Production target: **https://anvithbizcap.com** on Hostinger VPS `31.97.231.61`.

## Architecture

| Layer | Tech |
|---|---|
| Runtime | Node.js 20 LTS |
| Framework | Next.js 16.2 (app router) |
| ORM / DB | Prisma 7 + better-sqlite3 |
| Process supervisor | PM2 |
| Reverse proxy / TLS | nginx + Let's Encrypt |
| Source of truth | `git@github.com:FintaleAI/Anvith` (main branch) |
| Deploy trigger | `git push production main` → bare-repo `post-receive` hook on VPS |

## Persistent paths on the VPS

| Path | Purpose |
|---|---|
| `/var/www/anvithbizcap` | Source checkout (`.next`, `node_modules`, `package.json`, etc.) |
| `/var/lib/anvithbizcap/prod.db` | SQLite database — survives deploys |
| `/root/anvithbizcap-website.env` | Production env file (DATABASE_URL, JWT_SECRET) |
| `/root/repos/anvithbizcap.git` | Bare repo for push-to-deploy |
| `/etc/nginx/sites-available/anvithbizcap` | Nginx vhost (HTTPS + reverse proxy) |
| `/etc/letsencrypt/live/anvithbizcap.com/` | TLS cert (auto-renewed) |

## Production env vars

```
DATABASE_URL="file:/var/lib/anvithbizcap/prod.db"
JWT_SECRET="<64-char hex generated by openssl rand -hex 32>"
PORT=3020
NODE_ENV=production
```

These live in `/root/anvithbizcap-website.env` on the VPS only. The local `.env`
is never committed (gitignored). Use `.env.example` as a reference for what keys are needed.

## How a normal deploy works

```bash
# From your laptop:
git add .
git commit -m "What changed"
git push origin main         # → GitHub (history)
git push production main     # → triggers VPS post-receive hook
```

The post-receive hook on the VPS does:

```bash
# 1. Check out source to /var/www/anvithbizcap
# 2. cd into it
# 3. npm ci --include=dev            (Next.js build needs dev deps)
# 4. npx prisma generate
# 5. npx prisma migrate deploy       (applies any new migrations idempotently)
# 6. npm run build                   (compile .next/)
# 7. pm2 reload anvithbizcap-website (zero-downtime restart)
```

Typical deploy time: 60-120 seconds for code-only changes; up to 4 min if `node_modules` changed.

## Initial bootstrap (one-time, already done on the VPS)

```bash
# As root on VPS:

# 1. Install Node 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs build-essential

# 2. Install PM2
npm install -g pm2

# 3. Create persistent dirs
mkdir -p /var/lib/anvithbizcap
mkdir -p /var/www/anvithbizcap

# 4. Write production env file
cat > /root/anvithbizcap-website.env <<EOF
DATABASE_URL="file:/var/lib/anvithbizcap/prod.db"
JWT_SECRET="$(openssl rand -hex 32)"
PORT=3020
NODE_ENV=production
EOF
chmod 600 /root/anvithbizcap-website.env

# 5. Update the bare-repo post-receive hook (see deploy/post-receive in this repo)

# 6. First-time database setup
cd /var/www/anvithbizcap
set -a; source /root/anvithbizcap-website.env; set +a
npm ci --include=dev
npx prisma generate
npx prisma migrate deploy
node scripts/seed.mjs           # creates first admin
node scripts/seed-content.mjs   # sample blogs/news/MFs
npm run build

# 7. Start under PM2
pm2 start npm --name anvithbizcap-website --update-env -- run start
pm2 save
pm2 startup systemd             # follow the printed instruction once

# 8. Reconfigure nginx as reverse proxy (see deploy/nginx.conf)
ln -sf /etc/nginx/sites-available/anvithbizcap /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

## Verifying a deploy

```bash
# Local laptop:
curl -sI https://anvithbizcap.com/ | head -5    # → HTTP 200, content-type: text/html
curl -sI https://anvithbizcap.com/admin/login  # → HTTP 200 (login page)
curl -sI https://anvithbizcap.com/api/leads     # → 401 or 405 — protected

# On VPS:
pm2 status anvithbizcap-website                  # → online
pm2 logs anvithbizcap-website --lines 50         # → no recurring errors
ls -la /var/lib/anvithbizcap/prod.db             # → file exists, growing
```

## Rolling back

```bash
# Find a good commit:
git log --oneline origin/main | head

# Hard-reset production:
git push production <good-sha>:main --force

# Or trigger manually on VPS:
ssh root@anvithbizcap.com 'cd /var/www/anvithbizcap && git fetch /root/repos/anvithbizcap.git && git checkout <good-sha> && npm ci --include=dev && npx prisma generate && npm run build && pm2 reload anvithbizcap-website'
```

## Database backups

```bash
# Daily SQLite snapshot (add to root crontab):
0 3 * * * sqlite3 /var/lib/anvithbizcap/prod.db ".backup /var/lib/anvithbizcap/backups/prod-$(date +\%Y\%m\%d).db" && find /var/lib/anvithbizcap/backups -name 'prod-*.db' -mtime +30 -delete
```

## Common issues

| Symptom | Fix |
|---|---|
| `pm2 logs` shows `PrismaClientInitializationError` | DATABASE_URL points at wrong path or DB file unreadable — check `/root/anvithbizcap-website.env` |
| 502 Bad Gateway from nginx | Next.js process down — `pm2 restart anvithbizcap-website` |
| Hook fails on `npm ci` after a deploy | Wipe `node_modules` and `package-lock.json` on VPS, re-run. May happen after a Node major upgrade. |
| Build fails with "out of memory" | Pass `NODE_OPTIONS=--max-old-space-size=2048` before `npm run build` |
| First admin login doesn't work | Re-run `node scripts/seed.mjs` — it prints the seeded admin email/password |
